# 轻量化开放平台 UX 视觉质量审查

**日期：** 2026-08-12  
**选择方向：** 方向一“接入指挥台”  
**设计基础：** shadcn/ui + 青灰技术主题

## 结论

UX 方案通过设计阶段视觉质量门槛，可进入信息架构细化、原型和开发拆分。设计方向与一期客户规模、低频开发者任务和三个月交付边界匹配。当前审查针对 UX 规格与 HTML 方向预览，不替代实现完成后的浏览器、无障碍和真实设备验收。

## shadcn/ui 组件覆盖

- [x] 平台壳层映射到 Sidebar、Sheet、Breadcrumb。
- [x] 总览、应用、权限和统计映射到 Card、Table、Badge、Progress。
- [x] 表单映射到 Form、Input、Textarea、Checkbox、Select。
- [x] 普通与危险确认分别映射到 Dialog 和 AlertDialog。
- [x] 文档与调试映射到 Accordion、Tabs、ScrollArea、ResizablePanel。
- [x] 产品特定复合行为已定义为项目组合组件。

- [x] 背景、前景、卡片、主色、弱化色、边框、输入、焦点和危险色均有语义令牌。
- [x] 沙箱与生产使用独立语义色及文字标签。
- [x] 预览未使用装饰性渐变或无业务含义颜色。
- [x] 圆角、间距、控件高度和表格密度具有统一基线。

## 预览验证状态与已知缺陷

**状态：** 已运行桌面与移动端浏览器验证。  
**已知缺陷：** HTML 预览是方向决策稿，不包含生产级键盘逻辑、真实表格数据量、读屏语义和完整后端交互；这些项目已列为实现验收门槛。未发现阻断方向选择的重叠、裁切或对比问题。

## 无障碍检查

- [x] WCAG 2.2 AA 被设为目标。
- [x] 状态和环境不只依赖颜色。
- [x] 键盘覆盖的九项关键流程已封闭列出。
- [x] 焦点、浮层恢复、错误关联和实时反馈策略已定义。
- [x] 触控目标、200% 缩放和减少动态效果要求已定义。

## 反模式清理

- [x] 无装饰性渐变或漂浮色块。
- [x] 无大型无意义欢迎横幅。
- [x] 无卡片嵌套卡片作为通用布局。
- [x] 无仅为视觉丰富而存在的图表。
- [x] 无含糊状态名称或仅颜色状态。
- [x] 无需要定制组件才能实现的主要页面骨架。
